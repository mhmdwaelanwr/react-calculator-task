# React Calculator Task

A simple calculator application made with React and Vite for a front-end training task.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Percentage
- Positive / negative numbers
- Decimal numbers
- Delete last digit
- Clear calculator
- Responsive layout

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
